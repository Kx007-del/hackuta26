## Suggested use in Run It Back
These placements are product recommendations, not claims of brand approval.
- Header and loading screen: the supplied logo variant appropriate to the background.
- Hero and premiere title card: a supplied main wordmark.
- Headlines: an appropriate supplied display font.
- Instructions, controls and descriptions: Source Sans Pro.
- Landing and challenge cards: supplied Tiger Camo artwork as a supporting texture.
- Secondary surfaces: Circuit, Diamond and FaZe Up Camo after conversion and guideline review.
- Gift pattern: a rewards or campaign surface if added later.
- Arena: restrained branding on signs and surrounding surfaces, keeping targets clear.
- Premiere: supplied logo and wordmark with player credits.

Preserve all source alternatives. Use the appropriate variants across the experience; all variants do not need to appear at once.

## Implementation notes
PNG/JPG and WOFF/WOFF2 files are ready as source assets for a browser project. Illustrator originals and PDF artwork need suitable export or conversion for web use; they have been preserved, not converted. The Compressa ZIP remains intact. Fonts have not been globally installed.

The folder contains multiple guideline versions with differences, including typography recommendations that do not exactly match the supplied font set. Do not assume any one PDF is the latest solely from its filename. Refer to original visual guides when choosing logo variants and layout. Keep marks intact and follow the provided usage guidance.

No app has been implemented and no assets have yet been placed into app screens.
